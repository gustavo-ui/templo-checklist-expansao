# Templo Jiu-Jitsu: Checklist: Estrutura de Expansão

Checklist com tudo o que a Templo Jiu-Jitsu precisa estruturar para expandir no modelo de licença de marca.

## Estrutura

```
index.html        Página completa
assets/logo.svg   Símbolo da marca
```

## Publicar no GitHub Pages

1. Suba os arquivos no repositório
2. Vá em Settings > Pages
3. Em Source, escolha a branch `main` e a pasta `/ (root)`
4. Salve e aguarde o link ser gerado
